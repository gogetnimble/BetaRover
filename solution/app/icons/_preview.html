To use in the model-driven app:
1. Add each SVG as a Web Resource — type SVG (Vector format), e.g. name bvr_ember-dashboard.svg, upload the file.
2. In the app's site map, open each subarea → Icon → Web resource → pick the matching icon. Use ember-app.svg as the app's own icon.
3. Publish. The currentColor fill makes them adapt to light/dark and selection state automatically.
